Why double-clicking an MD file often fails

An MD file is a plain-text document that uses Markdown — a lightweight way to mark headings, lists, links, code, and emphasis with ordinary characters. The usual extension is .md (sometimes .markdown). ChatGPT, Claude, GitHub, and many note apps export or share files this way. The problem is not that the file is broken. The problem is that neither Windows nor macOS ships with a default app for .md, so when you double-click, the OS may ask “how do you want to open this?”, open Notepad/TextEdit with a wall of # and * symbols, or show something that looks nothing like the formatted document you expected.

Raw text and rendered Markdown are different experiences. In a plain text editor you see the source: hash marks for headings, brackets for links, backticks for code. That is useful if you are editing. If you only want to read the document — a README, meeting notes, an AI export — you usually want a preview: headings as headings, lists as lists, tables as tables. Knowing which you need helps you pick a tool. A text editor is enough when you must tweak a few lines. A Markdown viewer (desktop or browser) is better when you need the formatted reading view without installing a full IDE.

This guide walks through how to open an MD file on Windows, Mac, iPhone, and Android, then shows the browser path that works on any device when nothing is associated with .md. How to open an MD file on Windows

Windows does not associate .md with a built-in viewer. Common options:

  • Notepad — Right-click the file → Open with → Notepad. You will see raw Markdown source. Fine for a quick peek; poor for long documents with tables or code fences.
  • VS Code (free) — Install Visual Studio Code, open the file, then press Ctrl+Shift+V (or use the preview icon) for a side-by-side or preview pane. Excellent if you already write code; heavier than you need for a single README.
  • Typora-class editors — Desktop Markdown apps that show a live preview while you type. Useful if you edit Markdown daily; optional if you only need to open one file.
  • Associate .md — In Windows you can set a default app via Open with → Choose another app → check “Always use this app.” Pick Notepad, VS Code, or another editor you trust. Association helps next time, but it still does not give every user a rendered preview unless the chosen app supports one.
  • Browser path — If installing is blocked or you only need a reading view, drop the file into the viewer on this page or the homepage. You get GitHub-flavored rendering without changing system defaults.

Tip: email attachments named notes.md sometimes download as notes.md.txt. Rename back to .md if your editor filters by extension, or open the .txt content anyway — Markdown is still plain text.

How to open an MD file on Mac

macOS is similar: no first-party Markdown reader is tied to .md by default.

  • TextEdit — Opens .md as plain text. Switch to plain-text mode if rich text mangles characters. You will see source, not a rendered article.
  • Quick Look — Select the file in Finder and press Space. Quick Look can show a basic preview for some Markdown files, but support varies by macOS version and plugins. Tables, Mermaid diagrams, and math often look incomplete.
  • VS Code / MacDown-class editors — VS Code preview with Cmd+Shift+V is a solid local option. MacDown and similar apps focus on Markdown reading and writing with fewer IDE features.
  • Browser option — Safari or Chrome on the Mac can use the same drop / Choose file flow as Windows. Handy on shared Macs where you should not install apps, or when you want PDF/Word export after reading.

If Finder shows a generic blank icon for .md, that only means no default app is set — the file itself is still readable text.

How to open an MD file on iPhone / iPad

On iOS and iPadOS you often receive .md files through Mail, Files, iCloud Drive, or a share sheet from another app.

  • Files app — Locate the download, tap to preview. iOS Quick Look may show a limited Markdown view. Long documents, nested lists, and code blocks are frequently flattened.
  • Compatible editors — Apps such as iA Writer, 1Writer, or other Markdown editors can open from Files via Share → the app name. Install only if you edit Markdown on the go regularly.
  • Browser on mobile — Open Safari (or Chrome), visit this site, tap Choose file, and pick the .md from Files / Recents. The viewer is touch-friendly: pinch-friendly layout, readable typography, and the same local parse model as desktop. This is usually the lowest-friction way to get a proper reading view without another App Store install.

If the share sheet does not list a browser, save the attachment to Files first, then choose it from the site’s file picker.

How to open an MD file on Android

Android similarly lacks a universal system Markdown preview.

  • Files + text apps — The Files app (or Downloads) can open .md in a plain-text viewer or a third-party editor. You will typically see raw source unless the app includes a Markdown preview mode.
  • Editor apps — Markor and other open-source editors can preview Markdown locally. Worth installing if you keep a notes vault on the phone; optional for a one-off file from email.
  • Browser upload path — In Chrome, open this page, tap Choose file, and select the download. Rendering stays on-device. After reading, you can export to PDF when you need to share a formatted copy that colleagues can open without Markdown knowledge.

Watch for apps that insist on cloud sync before preview. If privacy matters, prefer a local editor or this browser-local viewer over services that require an account upload.

How to open a Markdown file from ChatGPT or Claude

AI assistants often offer “Download,” “Export,” or a copy button that yields Markdown. Typical flow:

  1. In ChatGPT or Claude, export or download the answer as .md (wording varies by product and plan).
  2. Save the file to Downloads, Desktop, or Files.
  3. Open it with any method above — Notepad/TextEdit for a quick source check, VS Code for editing, or the browser viewer on this page for formatted reading and PDF/Word export.

If the model only gives you a fenced code block in the chat UI, use Paste text on the homepage: paste the Markdown, render it, then export if needed. That avoids saving a file at all. Want PDF or Word instead?

Sometimes the goal is not to keep a .md file around, but to hand someone a PDF they can annotate, or a Word doc they can edit in Google Docs / Microsoft Word. After you open the file in the on-page viewer or on the homepage:

  • Use the PDF control in the top toolbar to save a printable document.
  • Use the Word control when you need .docx for further editing.
  • Or copy rich text from the preview into email, Docs, or Word manually.

Dedicated paths also live under MD to PDF and MD to Word if you arrived looking for conversion first. If your intent is to publish Markdown as a web page rather than open it for reading, sister tool mdtohtml.app focuses on convert-and-publish — keep that separate from the “open / read” job this guide covers.

Bottom line: how to open an MD file and how to open a Markdown file are the same task. Use a local editor when you will edit often; use the browser viewer when you need a formatted read on any device without installing software; export to PDF or Word when recipients do not speak Markdown.

FAQ

Why does double-clicking an MD file not work?

Neither Windows nor macOS ships with an app associated with the .md extension, so the system does not know what to open. Use a text editor, or open it in this page's viewer.

Do I need to install anything?

No. The online viewer on this page opens .md files with formatting on any device, with nothing to install.

Can I open MD files offline?

Locally installed editors work offline. This web viewer keeps working for an already-loaded page.

What is the difference between an MD file and a Markdown file?

None in practice: .md is the usual extension for a Markdown file. "How to open an MD file" and "how to open a Markdown file" are the same task.

Is my MD file uploaded when I open it here?

No. The viewer parses the file in your browser. See also open Markdown without uploading.
