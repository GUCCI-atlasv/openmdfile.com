The fastest way (any device)

Drop the file into the viewer at the top of this page. It renders instantly, works on every OS and phone, and the file never leaves your browser. Done.

On Windows

Windows has no default app for .md. Your options:

  • Notepad — right-click the file → Open with → Notepad. You'll see raw text with # and * symbols, readable but unformatted.
  • VS Code (free) — open the file and press Ctrl+Shift+V for a formatted preview.
  • Or skip the install — open it in this page's viewer with formatting intact.

On Mac

  • TextEdit — opens .md as plain text (unformatted).
  • Quick Look — select the file and press Space for a basic preview.
  • VS Code / editors — full preview with Cmd+Shift+V.
  • Or use the online viewer above — full GFM rendering including tables and diagrams.

On iPhone / iPad

iOS can Quick Look .md files from Mail or Files, but formatting is limited. For a proper reading view, open Safari, visit this page and pick the file from Files — the viewer is fully touch-friendly.

On Android

Android has no built-in markdown preview. Rather than installing an app for one file, open this page in Chrome and choose the file — it renders as a clean document you can also export to PDF.

最快的方法（任何设备）

把文件拖进本页顶部的查看器。立即渲染，任何系统和手机都可用，文件不离开浏览器。搞定。

Windows

Windows 没有 .md 的默认应用。你的选择：

  • 记事本——右键文件 → 打开方式 → 记事本。能看到带 # 和 * 符号的原始文本，可读但无排版。
  • VS Code（免费）——打开文件后按 Ctrl+Shift+V 查看格式化预览。
  • 或者跳过安装——直接在本页查看器中打开，排版完整。

Mac

  • TextEdit——以纯文本打开（无排版）。
  • 快速预览——选中文件按空格键，可做基础预览。
  • VS Code 等编辑器——Cmd+Shift+V 完整预览。
  • 或使用上方在线查看器——完整 GFM 渲染，含表格与图表。

iPhone / iPad

iOS 可以在邮件或“文件”中快速预览 .md，但排版有限。想要真正的阅读视图：打开 Safari 访问本页，从“文件”中选取——查看器完全适配触屏。

Android

Android 没有内置 Markdown 预览。与其为一个文件装一个 App，不如用 Chrome 打开本页选择文件——渲染为干净文档，还能顺手导出 PDF。

الطريقة الأسرع (على أي جهاز)

أفلت الملف في العارض أعلى هذه الصفحة. سيُعرض فورًا، ويعمل على كل نظام وهاتف، ولا يغادر الملف متصفحك. انتهى الأمر.

على Windows

لا يملك Windows تطبيقًا افتراضيًا لامتداد .md. خياراتك:

  • المفكرة — انقر بزر الفأرة الأيمن على الملف ← فتح باستخدام ← Notepad. سترى النص الخام برموز # و*، مقروءًا لكن بلا تنسيق.
  • VS Code (مجاني) — افتح الملف واضغط Ctrl+Shift+V لمعاينة منسقة.
  • أو تجاوز التثبيت — افتحه في عارض هذه الصفحة بتنسيق كامل.

على Mac

  • TextEdit — يفتح .md كنص بسيط بلا تنسيق.
  • النظرة السريعة — حدّد الملف واضغط مسافة لمعاينة أساسية.
  • VS Code والمحررات — معاينة كاملة عبر Cmd+Shift+V.
  • أو استخدم العارض أعلاه — عرض GFM كامل بما فيه الجداول والمخططات.

على iPhone / iPad

يستطيع iOS معاينة ملفات .md من البريد أو تطبيق «الملفات»، لكن التنسيق محدود. وللحصول على عرض قراءة حقيقي: افتح Safari وادخل هذه الصفحة واختر الملف من «الملفات» — فالعارض مهيّأ بالكامل للمس.

على Android

لا يتضمن Android معاينة ماركداون مدمجة. وبدل تثبيت تطبيق من أجل ملف واحد، افتح هذه الصفحة في Chrome واختر الملف — سيظهر كمستند نظيف يمكنك أيضًا تصديره إلى PDF.

تريد الملف بصيغة أخرى؟

حوّله مرة واحدة وتخلَّص من القلق: MD إلى PDF للمشاركة، وMD إلى Word للتحرير.

सबसे तेज़ तरीक़ा (किसी भी डिवाइस पर)

फ़ाइल को इस पेज के ऊपर मौजूद व्यूअर में छोड़ें। यह तुरंत रेंडर होती है, हर OS और फ़ोन पर चलती है, और फ़ाइल कभी ब्राउज़र नहीं छोड़ती। हो गया।

Windows पर

Windows में .md के लिए कोई डिफ़ॉल्ट ऐप नहीं है। आपके विकल्प:

  • Notepad — फ़ाइल पर राइट-क्लिक → Open with → Notepad। आपको # और * प्रतीकों वाला कच्चा टेक्स्ट दिखेगा — पठनीय, पर बिना फ़ॉर्मैटिंग।
  • VS Code (मुफ़्त) — फ़ाइल खोलें और फ़ॉर्मैट प्रीव्यू के लिए Ctrl+Shift+V दबाएँ।
  • या इंस्टॉल छोड़ें — इसी पेज के व्यूअर में पूरी फ़ॉर्मैटिंग के साथ खोलें।

Mac पर

  • TextEdit — .md को सादे टेक्स्ट के रूप में खोलता है (बिना फ़ॉर्मैटिंग)।
  • Quick Look — फ़ाइल चुनें और स्पेस दबाएँ, बुनियादी प्रीव्यू मिलेगा।
  • VS Code / एडिटर — Cmd+Shift+V से पूरा प्रीव्यू।
  • या ऊपर वाला ऑनलाइन व्यूअर — टेबल और डायग्राम सहित पूरा GFM रेंडरिंग।

iPhone / iPad पर

iOS मेल या Files से .md का Quick Look कर सकता है, पर फ़ॉर्मैटिंग सीमित रहती है। सही रीडिंग व्यू के लिए Safari खोलें, यह पेज देखें और Files से फ़ाइल चुनें — व्यूअर पूरी तरह टच-फ़्रेंडली है।

Android पर

Android में बिल्ट-इन Markdown प्रीव्यू नहीं है। एक फ़ाइल के लिए ऐप इंस्टॉल करने के बजाय, Chrome में यह पेज खोलें और फ़ाइल चुनें — यह साफ़ दस्तावेज़ के रूप में रेंडर होती है जिसे आप PDF में एक्सपोर्ट भी कर सकते हैं।

फ़ाइल दूसरे फ़ॉर्मैट में चाहिए?

एक बार बदलें और निश्चिंत रहें: साझा करने के लिए MD से PDF, संपादन के लिए MD से Word।

FAQ

Why does double-clicking an MD file not work?为什么双击 MD 文件打不开？لماذا لا يعمل النقر المزدوج على ملف MD؟MD फ़ाइल पर डबल-क्लिक क्यों काम नहीं करता?

Neither Windows nor macOS ships with an app associated with the .md extension, so the system doesn't know what to open. Use a text editor, or open it in this page's viewer.

Windows 和 macOS 都没有预装关联 .md 扩展名的应用，系统不知道该用什么打开。可以用文本编辑器，或直接在本页查看器中打开。

لا يأتي Windows ولا macOS بتطبيق مرتبط بامتداد .md، لذا لا يعرف النظام بماذا يفتحه. استخدم محرر نصوص، أو افتحه في عارض هذه الصفحة.

न Windows और न macOS में .md एक्सटेंशन से जुड़ा कोई ऐप आता है, इसलिए सिस्टम को पता नहीं होता कि क्या खोले। टेक्स्ट एडिटर उपयोग करें, या इस पेज के व्यूअर में खोलें।

不需要。本页的在线查看器可在任何设备上以完整排版打开 .md 文件，无需安装。

لا. يفتح العارض في هذه الصفحة ملفات .md بتنسيق كامل على أي جهاز، وبلا أي تثبيت.

नहीं। इस पेज का ऑनलाइन व्यूअर किसी भी डिवाइस पर पूरी फ़ॉर्मैटिंग के साथ .md फ़ाइलें खोलता है, बिना कुछ इंस्टॉल किए।
