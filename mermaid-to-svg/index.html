Why export Mermaid as SVG

SVG is a vector format: the diagram stays sharp at any zoom level, the file is small, and text remains real text you can search, select and edit. That makes SVG the right choice for documentation sites, design files, print, and slides you will present on large screens.

SVG that opens properly outside the browser

Many Mermaid exporters produce SVG that only looks right in a browser. They wrap labels in HTML foreignObject elements and keep the colours in a stylesheet, so PowerPoint, Word and Figma show empty boxes or black shapes. This converter renders labels as native SVG text and writes the final colours, strokes and fonts onto every shape, so the file looks the same wherever you open it.

How to convert Mermaid to SVG

  1. Paste your Mermaid code or upload a .mmd file. The fenced ```mermaid wrapper is removed automatically.
  2. Pick a theme and, if you need it, a transparent background.
  3. Click Download SVG, or Copy SVG code to paste the markup straight into HTML, MDX or a CMS.

Using the SVG in other apps

  • PowerPoint and Word: Insert → Pictures → This Device. In Microsoft 365 you can right-click the SVG and choose Convert to Shape to edit boxes and text individually.
  • Figma, Sketch and Illustrator: drag the file onto the canvas; groups and text layers stay editable.
  • Confluence and wikis: attach the SVG to the page and insert it as an image. If your space does not allow SVG uploads, use the PNG converter instead.
  • Websites and docs: reference the file in an <img> tag, or paste the copied markup inline.

FAQ

Will the text be editable in PowerPoint?

Yes. Labels are exported as SVG text rather than embedded HTML, so after Convert to Shape in Microsoft 365 the text and boxes can be edited individually.

Why does my SVG from other tools show missing labels?

Those exports usually put labels in foreignObject elements, which Office and many design tools ignore. This converter avoids foreignObject and writes styles inline.

Should I choose SVG or PNG?

Choose SVG for slides, print, design tools and websites where you want sharp, editable output. Choose PNG for chat apps, issue trackers, email and anywhere that does not accept SVG.

Can I export with a transparent background?

Yes. Tick Transparent before downloading; otherwise the SVG gets a solid background that matches the selected theme.
