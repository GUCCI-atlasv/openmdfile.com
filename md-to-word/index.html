Markdown to Word, without the mess

Copy-pasting raw markdown into Word gives you hashtags and pipes instead of headings and tables. This tool converts markdown to Word properly: heading levels map to Word styles, tables become real tables, lists keep their nesting and code blocks stay monospaced.

Two ways to get your document into Word

  1. Download as Word — open your file above, click the Word button, and save a document that opens in Microsoft Word, LibreOffice or Pages.
  2. Copy rich text — click Copy rich text and paste straight into an open Word or Google Docs document. Formatting comes along.

Common uses

  • Turning ChatGPT / Claude output into a shareable office document
  • Submitting markdown notes as coursework or reports
  • Moving documentation into a company template for further editing

As always on openmdfile, the conversion runs locally in your browser — nothing is uploaded. Need a fixed-layout file instead? Use MD to PDF.

Markdown 转 Word，不再一团糟

把原始 Markdown 直接粘进 Word，得到的是井号和竖线，而不是标题和表格。本工具把 Markdown 正确地转换为 Word：标题层级映射为 Word 样式，表格变成真实表格，列表保留嵌套，代码块保持等宽字体。

两种方式进入 Word

  1. 下载 Word 文件——在上方打开文件，点击 Word 按钮，保存的文件可在 Microsoft Word、LibreOffice、Pages 中打开。
  2. 复制富文本——点击“复制富文本”，直接粘贴到已打开的 Word 或 Google Docs 文档中，格式随之而来。

常见用途

  • 把 ChatGPT / Claude 的输出变成可分享的办公文档
  • 把 Markdown 笔记整理为作业或报告提交
  • 把文档迁入公司模板继续编辑

一如既往，转换在浏览器本地完成——不上传任何内容。需要固定排版的文件？请用 MD 转 PDF。

ماركداون إلى Word بلا فوضى

لصق نص ماركداون الخام في Word يمنحك علامات ورموزًا بدل العناوين والجداول. تحوّل هذه الأداة ماركداون إلى Word بالشكل الصحيح: تُترجَم مستويات العناوين إلى أنماط Word، وتصبح الجداول جداول حقيقية، وتحافظ القوائم على تداخلها، وتبقى كتل الشيفرة بخط أحادي المسافة.

طريقتان لنقل مستندك إلى Word

  1. تنزيل كملف Word — افتح ملفك أعلاه، اضغط زر Word، واحفظ مستندًا يفتح في Microsoft Word أو LibreOffice أو Pages.
  2. نسخ نص منسق — اضغط «انسخ نصًا منسقًا» والصقه مباشرة في مستند Word أو Google Docs مفتوح، وسيأتي التنسيق معه.

Markdown से Word, बिना गड़बड़ी के

कच्चा Markdown सीधे Word में पेस्ट करने पर हेडिंग और टेबल की जगह हैश और पाइप दिखते हैं। यह टूल Markdown को सही तरीक़े से Word में बदलता है: हेडिंग स्तर Word स्टाइल्स से मैप होते हैं, टेबल असली टेबल बनती हैं, सूचियाँ अपनी नेस्टिंग रखती हैं और कोड ब्लॉक मोनोस्पेस रहते हैं।

Word में लाने के दो तरीक़े

  1. Word के रूप में डाउनलोड करें — ऊपर फ़ाइल खोलें, Word बटन दबाएँ, और ऐसा दस्तावेज़ सेव करें जो Microsoft Word, LibreOffice या Pages में खुलता है।
  2. रिच टेक्स्ट कॉपी करें — “रिच टेक्स्ट कॉपी करें” दबाएँ और सीधे खुले Word या Google Docs दस्तावेज़ में पेस्ट करें। फ़ॉर्मैटिंग साथ आती है।

आम उपयोग

  • ChatGPT / Claude के आउटपुट को साझा करने योग्य ऑफ़िस दस्तावेज़ बनाना
  • Markdown नोट्स को असाइनमेंट या रिपोर्ट के रूप में जमा करना
  • डॉक्युमेंटेशन को कंपनी टेम्पलेट में ले जाकर आगे संपादित करना
