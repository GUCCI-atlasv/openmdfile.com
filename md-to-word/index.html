How to convert Markdown to Word

  1. Open your Markdown. Drop a .md, .markdown or .txt file onto the box above, choose it from your device, paste the text, or open a raw link (a GitHub raw URL works well). Files up to 10 MB are supported.
  2. Check the preview. Your document renders with real headings, tables and lists, so you can spot problems before you export.
  3. Click Word. A Word document downloads straight away. Open it in Microsoft Word, LibreOffice Writer or Apple Pages and keep editing.

Prefer to work in a document that is already open? Click Copy rich text instead and paste into Word or Google Docs — the formatting comes with it.

When to use MD to PDF instead

Word is the right choice when someone needs to edit the document. If your Markdown relies on Mermaid diagrams or LaTeX formulas, or the layout must look exactly the same on every device, convert Markdown to PDF instead — diagrams and math are kept there.

Download or copy: which should you use?

Download Word gives you a standalone file — best for email attachments, coursework submissions and anything you want to archive.

Copy rich text is faster when the destination document is already open. It is also the easiest way to get Markdown into Google Docs: copy here, then paste into your Doc. You can also upload the downloaded Word file to Google Drive and open it with Google Docs.

Convert ChatGPT and Claude output to Word

AI assistants write in Markdown. When you copy an answer from ChatGPT, Claude or Gemini into Word, you often get stray #, ** and | characters instead of headings, bold text and tables. Paste the answer into this page (or save it as an .md file and drop it in), check the preview, and download a clean Word document — ready to hand to a colleague, a teacher or a client.

Why not paste Markdown straight into Word?

Word does not understand Markdown syntax. Pasting raw text keeps every symbol, flattens tables into lines of pipes and loses your heading structure, so you end up re-formatting by hand. Converting first turns the syntax into proper Word styles, which also means you can apply your company template or generate a table of contents in one click.

Your file stays on your device

The conversion runs entirely in your browser with JavaScript. Your Markdown is never uploaded to our servers, so it is safe to convert internal documents, drafts and notes. Once the page has loaded, it even keeps working offline. Learn more in how to open Markdown without uploading it.

FAQ

Is the Word file editable?

Yes. It is a normal Word document: you can change text, restyle headings, edit tables and apply your own template.

Which file format do I get?

A .doc Word document. It opens in Microsoft Word (Windows and Mac), LibreOffice Writer and Apple Pages. If you need .docx, open the file in Word and choose File → Save As → Word Document (.docx).

Can I convert Markdown to Google Docs?

Yes. Use Copy rich text and paste into a Google Doc, or upload the downloaded file to Google Drive and open it with Google Docs.

Does it work on a phone?

Yes. You can open a .md file and download the Word document on iPhone and Android. Copy rich text works best on desktop.

Is it really free? Any watermark?

Free and unlimited, with no watermark, no account and no ads.

What if my file is not Markdown?

Plain .txt files open too. To learn more about the format, read what is an MD file, or see how to open an MD file on Windows, Mac, iPhone and Android.
